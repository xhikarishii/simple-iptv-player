⚙️ Global Settings

Changes the identity of the player when connecting to IPTV servers. Useful for bypassing strict server restrictions.

Controls how the player selects the UI layout when first loaded. Applies to all users.

Choose a pre-configured profile to optimize buffering, latency, and quality strategy.

If enabled, HTTPS streams will be routed through the server. If disabled, they will be fetched directly.

⚠️ Note: Disabling this will prevent custom User-Agent spoofing from working on HTTPS streams, which may cause some servers to reject the connection.

If enabled, browser developer tools and right-click menus will be allowed. NOT RECOMMENDED FOR PRODUCTION.
